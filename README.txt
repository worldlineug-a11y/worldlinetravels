Files:

How to use:
1. Open index.html in a modern browser.
2. The website works as a static site; no server/database is required for the booking form.
3. Booking requests open WhatsApp using +256 770 313 440.
4. Replace the payment placeholders with the correct official payment numbers before publishing.
5. The website uses remote Unsplash images, Google Fonts and Font Awesome, so internet access is needed for those visual assets/icons.

Publishing:
Upload index.html to any static web host (for example your normal hosting/cPanel public_html folder).
